# 🛠️ CONTRIBUTING GUIDELINES

Thank you for wanting to make **Cobalt Tavern** better! 
Since this engine is built with a focus on absolute control and operates under a **proprietary license**, the contribution process differs from standard Open-Source projects.

## 🚫 NO FORKS OR PULL REQUESTS (PR)
According to the [License](LICENSE), public copying (Forking) and redistribution of modified source code is **PROHIBITED**. 
**Please DO NOT submit Pull Requests. They will be closed automatically.**

## 💡 How can you help the project?

You can make a massive impact by reporting bugs and suggesting brilliant ideas! All contributions are handled exclusively via [Issues](https://github.com/GrishaDeLumiere/Cobalt-Tavern/issues).

### 🐛 1. Bug Reports (Found an error?)
If something explodes, the UI breaks, or the backend throws a fatal exception:
1. Ensure you are running the latest version (Latest Commit).
2. Check existing Issues to see if it has already been reported.
3. Open a new Issue with the **`[BUG]`** prefix.
4. Attach screenshots, browser console logs (F12), or terminal traces. Provide clear steps to reproduce the crash.

### 🚀 2. Feature Requests (Have an idea?)
Got a genius idea on how to improve the chat manager or add a new context generation feature?
1. Open an Issue with the **`[FEATURE]`** or **`[IDEA]`** prefix.
2. Describe in detail why it is needed and how it should work (mockups or logic flowcharts are highly appreciated).

### 💻 3. Have ready-to-use code (Backend Patch)?
Currently, the UI source code (Frontend) is closed and shipped as a compiled bundle. **Only the server-side code (Node.js/Fastify) is open for inspection.**
If you tinkered with the backend code and wrote a solid fix or feature you want to share:
1. Open an Issue with the **`[PATCH]`** prefix.
2. Paste your backend code directly into the Issue body (using ` ```javascript ` code blocks).
3. Explain which server file needs to be updated and what the code achieves.
4. The author will review your snippet, and if it meets the AAA standards, it will be integrated into the core!
