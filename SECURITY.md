# 🛡️ ПОЛИТИКА БЕЗОПАСНОСТИ

**Cobalt Tavern** — это ультимативный интерфейс, созданный для **ПОЛНОСТЬЮ ЛОКАЛЬНОГО** использования. Ядро не отправляет телеметрию, не связывается с внешними серверами и не сливает ваши данные. Ваши промпты, лорбуки и логи навсегда остаются только на вашем жестком диске.

⚠️ **ВАЖНО:** Если вы решаете пробросить порты (`0.0.0.0`) и выставить интерфейс в публичный интернет — **это исключительно ваша ответственность**. Проект не предназначен для использования в качестве публичного веб-сервиса, и автор не несет ответственности за взломы ваших серверов.

## 🟢 Поддерживаемые версии

Проект находится в стадии активной разработки. Официальные патчи и исправления уязвимостей выпускаются только для последней версии.

| Ветка / Релиз | Статус |
| :--- | :--- |
| `main` (Последний коммит) | ✅ Поддерживается |
| Старые версии | ❌ Не поддерживаются |
| Неофициальные форки | 🚫 **НЕЛЕГАЛЬНЫ И НЕ ПОДДЕРЖИВАЮТСЯ** |

## 🎯 Область угроз (Что мы фиксим)

Поскольку программа локальная, традиционные веб-уязвимости (типа DDoS) нас не волнуют — если только вы не ддосите сами себя. Мы обращаем внимание на уязвимости, которые могут навредить вашему ПК при импорте чужих данных:

**Рассматривается (Будет исправлено):**
- **Path Traversal:** Возможность скрипта/запроса выйти за пределы директории `data/` и получить доступ к файлам ОС.
- **RCE (Remote Code Execution):** Выполнение вредоносного кода при импорте чужих карточек персонажей (`.png`/`.json`) или бэкапов чатов (`.jsonl`).
- **Критические краши ядра:** Баги, вызывающие фатальный отказ бэкенда (Fastify) при обработке специфичного синтаксиса.

**Игнорируется (Ваши проблемы):**
- Атаки, требующие физического доступа к вашему ПК.
- Уязвимости сторонних серверов LLM (KoboldCpp, LM Studio и др.).
- Взломы, произошедшие из-за хостинга проекта в открытом интернете без VPN/Tunnel.

## 🚨 Как сообщить об уязвимости

Если вы нашли критическую дыру в безопасности ядра:
1. Создайте новый [Issue](https://github.com/GrishaDeLumiere/Cobalt-Tavern/issues) в этом репозитории.
2. В названии обязательно укажите тег **`[SECURITY]`** (например: `[SECURITY] Path Traversal при загрузке фона`).
3. Приложите понятный лог или шаги для воспроизведения.

Мы ответим и выкатим патч в кратчайшие сроки.
